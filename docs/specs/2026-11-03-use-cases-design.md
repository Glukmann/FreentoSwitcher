# FreentoSwitcher — модель поведения (юзкейсы, шаги, отклонения)

Статус: согласовано с пользователем (2026-11-03, правки: единственная клавиша Option;
выделение без лимита длины; автокоррекция Apple отключена пользователем).
Этот документ — единственный источник истины о том, ЧТО должна делать программа.
Код и тесты пишутся под спеку, а не наоборот.

## 0. Состояния системы

| Состояние | Где | Что хранит |
|---|---|---|
| Буфер набора (raw) | Engine | keycode-штрихи с момента последнего разделителя/сброса |
| Пара переключения | Engine | (текущий текст + раскладка, другой текст + раскладка) последней конвертации слова — для бесконечного туда-обратно |
| Пара выделения | App | (original, converted) последней конвертации выделения |
| Настройки | persisted | раскладки, хоткеи, флаги, исключённые приложения |
| Окружение | система | раскладка, выделение, буфер обмена, фронт-приложение |

## Инварианты (то, что держим любой ценой)

- **I1.** Word-путь (backspace'ы + вставка) выполняется ТОЛЬКО при подтверждённо пустом выделении.
- **I2.** Сколько символов стёрли — столько же вставили: deleteCharacters(N), N = длина заменяемого текста в графемах.
- **I3.** Реплей посимвольный через таблицу ЦЕЛЕВОЙ раскладки; символа без клавиши — unicode-фолбэк. Ничего не теряется.
- **I4.** После конвертации выделения буферы набора и пара переключения сбрасываются (защита от фантомных штрихов).
- **I5.** Разделители слова = только пробел, enter, tab. Пунктуация слово не рвёт.
- **I6.** Пунктуация конвертируется тождественно ('.' → '.'), меняются только буквы.
- **I7.** Автоконвертация: словарь ищется по ЯДРУ из букв (не-буквы с краёв отрезаются).
- **I8.** Буфер обмена пользователя после любой операции = как до неё (снапшот + восстановление; primary-путь выделения буфер вообще не трогает).
- **I9.** В исключённом приложении FreentoSwitcher полностью прозрачен: никакого синтеза, хоткеи не работают.
- **I10.** Набранное слово длиннее 32 символов не конвертируется (ограничение буфера набора; I2 важнее конвертации). На выделение лимит не распространяется — страница целиком конвертируется.

## UC-1. Автоконвертация слова по разделителю

Предусловие: Auto Conversion включена, текущая раскладка EN.

1. Пользователь печатает слово посимвольно. Каждый keyDown: не разделитель, печатает символ → в буфер набора. Шумовые keycode (AltGr и пр., не дающие символа) игнорируются. Backspace стирает последний штрих. Escape сбрасывает буфер набора и пару переключения.
2. Пользователь жмёт разделитель (пробел/enter/tab):
   a. Буфер пуст → ничего, разделитель уходит в приложение.
   b. Буфер переполнен (> 32, штрихи обрезались) → НЕ конвертируем, буферы сброшены, разделитель уходит в приложение (I10).
   c. Раскладка RU → слово корректно, не трогаем, буферы сброшены.
   d. Иначе: typed = буфер, прочитанный через таблицу текущей раскладки (= то, что видит пользователь).
   e. Вердикт = словарь по ядру из букв (I7).
   f. .incorrectLayout → converted = конвертация typed (I6), смена раскладки (ждём подтверждения до 500 мс), удаление typed.count символов (I2), вставка converted посимвольно (I3), звук, буферы сброшены; разделитель уходит в приложение уже в новой раскладке.
   g. .unknown/.exception → ничего, буферы сброшены.

## UC-2. Быстрая клавиша Option — единственная клавиша управления

Предусловие: хоткей = Option в одиночку (нажат и отпущен без других клавиш между).

1. Option нажат → трекер фиксирует.
2. Между нажатием и отпусканием была другая клавиша → НЕ срабатывает (Option как модификатор).
3. Отпускание последнего Option без посторонних клавиш → хоткей сработал.
4. Опрос выделения через Accessibility (мгновенно):
   - **Выделения нет** (подтверждено) → word-путь СИНХРОННО:
     - Буфер набора непуст → принудительная конвертация слова (без словаря): typed, converted, удалить typed.count, вставить converted, сменить раскладку, звук. Пара переключения := (текущий: converted + целевая раскладка; другой: typed + исходная раскладка).
     - Буфер пуст, пара переключения есть → см. UC-3.
     - Оба пусты → ничего.
   - **Выделение есть** → асинхронно (чтобы не блокировать перехватчик): см. UC-5/UC-6. Буфер набора и пара переключения сбрасываются (I4).
   - **AX молчит** → асинхронно: читаем выделение через AX, иначе через буфер обмена, иначе word-путь.
5. Отдельной клавиши отмены (⌥`) в продукте нет: поле хоткея отмены по умолчанию не назначено (Hotkey.none). Вся работа — одной клавишей.

## UC-3. Переключение слова туда-обратно (бесконечное)

Предусловие: после UC-1 или UC-2; буфер набора пуст; выделения нет; пара переключения непуста.

1. Option → удалить текущий текст пары (current.text.count backspace'ов), вставить other.text через его раскладку (I3), сменить раскладку, звук.
2. Пара := (current: other, other: прежний current). Swap, не clear.
3. Повторные нажатия крутят по кругу бесконечно.
4. Любая печать → буфер набора наполняется заново; следующая конвертация перезапишет пару.

## UC-4. Быстрая смена раскладки без конвертации (⌘`)

1. Переключить RU↔EN системно, звук. Текст не трогаем.
2. В исключённом приложении не работает (I9).

## UC-5. Конвертация выделения (primary, через Accessibility)

Предусловие: текстовое выделение в AX-совместимом приложении. Лимита длины нет (I10 не применяется).

1. Option → AX-опрос: выделение есть → асинхронный путь.
2. AX readSelectedText → строка S (пусто/нет атрибута → fallback UC-6).
3. Если S == пара.converted → ОТКАТ: заменить выделение на пара.original, перевыделить original (UTF-16 длина), пара := swapped.
4. Иначе: mode = направление по преобладающему алфавиту; нет букв → ничего (выделение целое).
5. converted = конвертация S (I6). converted == S → ничего.
6. AX replaceSelection(converted) → атомарная замена выделения. Fail → ничего, пара не трогается.
7. Перевыделить converted (чтобы повторное нажатие сработало как откат). Fail → текст конвертирован, но откат в этом приложении не гарантирован (лог).
8. Пара := (S, converted); звук; системная раскладка := целевая.

## UC-6. Конвертация выделения (fallback, через буфер обмена)

Только если приложение не отдало AX-выделение.

1. Снапшот буфера обмена (все типы, все элементы).
2. Синтетический Cmd+C; ждём смены changeCount до 250 мс:
   - Не изменился → выделения нет (или приложение не отвечает): к word-пути (если AX молчал) или ничего. Буфер не тронут.
   - Изменился, строки нет (файл/картинка) → восстановить снапшот (I8), ничего.
   - Строка S → продолжаем.
3. Откат/конвертация как в UC-5 (по S).
4. Записать результат в буфер, синтетический Cmd+V, пауза 300 мс, восстановить снапшот (I8), перевыделить Shift+Left ×N (для больших выделений — постранично неточно, ограничение fallback).
   - **Известный риск**: если приложение обработает Cmd+V позже 300 мс, вставится восстановленное содержимое. Лечится только переходом на AX-путь в конкретном приложении; зафиксировано как ограничение fallback.

## UC-7. Галочка Auto Conversion

Переключает автоконвертацию (UC-1) немедленно, сохраняется между запусками. Ручная конвертация и выделение работают всегда.

## UC-8. Галочка Debug Logging

Вкл/выкл файлового лога ($TMPDIR/freento-debug.log, ротация 1 МБ). Каждый шаг каждого UC при включённом логе должен быть виден.

## UC-9. Запуск приложения

1. Загрузить настройки (старые версии JSON не сбрасываются, новые поля — дефолты).
2. Сохранённые раскладки не найдены в системе → авто-детект включённых (RU: *Russian*, EN: ABC→US→British), сохранить.
3. Построить прямые и обратные символьные таблицы для обеих раскладок.
4. Загрузить словарь триггеров, конвертировать в EN-форму.
5. Проверить Accessibility-право (нет — предупреждение в лог, перехватчик всё равно запускается).
6. Запустить перехватчик.

## UC-10. Исключённые приложения

События полностью прозрачны: не буферизуются, хоткеи не срабатывают, ничего не синтезируется (I9).

## Известные ограничения MVP (приняты осознанно)

- **L1.** Переключение слова после перемещения каретки мышью — без гарантий (D17), как в Punto.
- **L2.** Fallback-путь выделения через буфер имеет гонку paste→restore (UC-6 п.4) и неточное перевыделение больших кусков.
- **L3.** Автокоррекция Apple может изменить вставленный текст — не лечим (пользователь отключил).
- **L4.** userRules матчатся в текущей раскладке; UI для них — Plan B.
- **L5.** Набранные слова > 32 не конвертируются (I10); выделение не ограничено.
